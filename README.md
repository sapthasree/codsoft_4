# Predicting Sales Based on Advertising Data (Linear Regression Model)

## Internship at Codsoft (April 2025 - May 2025)

### Task Overview:
In this task, I worked on predicting sales based on advertising expenditures in three media channels: TV, Radio, and Newspaper. The goal was to create a Linear Regression model to predict sales (the target variable) based on these features.
